Future Learning Labs builds free, open-source software for students and teachers, starting with subjects that are conceptually hard to teach and poorly served by existing tools.

Descriptive geometry solver

A tutoring tool for descriptive geometry (Geometria Descritiva) — a subject taught to 10th/11th grade students that's notoriously hard because it requires translating 3D reasoning into 2D technical drawings. The tool reads a problem (typed or photographed), confirms its understanding with the student before solving, then walks through the construction step by step with a synchronized 2D diagram and a rotatable 3D model.

In development · built on Claude (Amazon Bedrock), AWS Lambda, S3, and CloudFront.
